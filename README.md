# Lloyds Customer Complaints Dashboard

Analysing customer complaint patterns from my experience inside Lloyds Banking Group (via Teleperformance) - retail banking support handling 50+ cases daily.

### Dataset
50 sample records: Date, Complaint_Type, Channel, Resolution_Time, Satisfaction, Customer_Type

### Tools
- Excel / Google Sheets (data creation, cleaning)
- Power BI (next: dashboard with top complaint types, avg resolution by channel)

### Key Insights (to be added after dashboard)
- Most common complaint type
- Channel with longest resolution time
- Link between resolution time and satisfaction
